KNOWN ROOT CAUSES FOUND BY READING THE 0.5.0-test SOURCE
- config.yml has `prices: {}` (EMPTY). That is why /sell shows $0 and cannot sell. Fill it from the price table in the reference file (material -> money per item).
- Auction/sort/page control slots are -1 in config, so the browse screen renders a blank grid with no buttons. The navigation row must always be built.
- Pay and listing flows are intentionally blocked until config slots/limits are set ("Pay confirmation positions still need your design", "Auction limit and fee still need to be configured").
- Scoreboard line settings do nothing because the owner's TAB config never references %lunar_*% placeholders; only the whole-scoreboard toggle (via TAB API) works.
- Heads use setOwningPlayer: fine on Java, no skin on Bedrock menus (Geyser limitation).

## 1. Auction shop (/ah, hopper "Shop")
- **Browse screen**: title `Auction (Page N)`. 5 rows (45 slots) of listings, newest first by default. Empty slots stay empty (no panes) when nobody has listed.
- **Bottom row, only our buttons**: slot 47 cauldron `Filter` / `Click to change` with options Default, Lowest Price, Highest Price, Recently Listed (current highlighted, click cycles); slot 51 chest `Your Items` / `Click to view`; slot 53 `Next page` / `Click to view next page`; slot 45 `Previous page` (page 2+ only, assumed).
- This bar must appear on EVERY shop screen. Bug: screens opened blank because Sort/Prev/Next slots were -1 in config.
- **Quick Search**: ender chest button. Position: owner said "add it without moving anything" -> main Shop menu bottom row: Shop 48, Search 49, Settings 50, Your Items chest 51, **Ender Chest 52**, Pay 53. Name `Quick Search`, line `Click to search`.
- **Search is per tab**: in Pay it searches online players; in the auction shop it searches listings. Sign text says `Search`.
- **Your Items**: title `Auction -> Your Items`, 6 rows, all the player's active listings; unused slots are red panes (kept on purpose); a sold listing disappears. Click-to-withdraw behavior was asked but not answered - open question.
- **/ah sell <price>** opens `Confirm Listing` (3 rows) and nothing else: red Cancel pane slot 11 (`Cancel` / `Click to cancel the sale`), held stack slot 13 (name + `You're going to sell this item for $ 1K`, green $), green Confirm pane slot 15 (`Confirm` / `Click to sell`). Exit/close = cancel. Whole stack at the typed total price (assumed). Listings never expire (no Time Left line).
- **Buying**: `Confirm Purchase` (3 rows): red Cancel 11 (`Click to cancel`), item 13 with name, `Price` (green) and `Seller` (aqua), green Confirm 15 (`Click to buy`). Replaces the old broken layout.
- Listing limit and fee were never decided (blocked flow) - still open.

## 5. TPA, RTP and spawns (own implementation)
- Own TPA modeled on SimpleTPA 1.6 (`references/uploaded-configs/SimpleTPA-1.6-config.yml`): /tpa, /tpahere, /tpaccept [player], /tpdeny [player], /tpacancel, /tpatoggle; cooldown 30s, request timeout 60s; request received message `<player> sent you a TPA-Request! /tpaccept or /tpdeny`; make accept/deny clickable (assumed). Replaces Essentials TPA.
- **Instant RTP**: teleports instantly (no 5 second wait) to a random safe spot within **20,000 blocks of spawn** in the world.
- **Random respawn on every death**, except players with a bed/respawn anchor spawn who respawn there.
- **First join** spawns at a random spot; later joins keep the logout position.
- Replaces BetterRTP.

## 6. TAB replacement (our own tab list, name tags, scoreboard)
- Spec = the uploaded TAB files in `references/uploaded-configs/tab/`. Ship switched OFF by default; remove the TAB jar only after it matches.
- Scoreboard (animated title lunarServer, divider, Player, Rank, Online, Money, Ping, SERVER TPS, divider, animated Discord line) with exact colors and hex gradients; per-line toggles built in: Money, Online, Ping, TPS, Discord Link, Rank Tag.
- Tab list: header = animated LunarVoid text, footer = animated Discord text (assumed - the config referenced missing animations lunarTitle/discordSweep); LuckPerms prefix/suffix; ping numbers; sort smp_owner, smp_manager, admin, mod, trusted, vip1, member, default, then A-Z.
- Name tags: rank tags, green `$` money under names, collision on. Display names: world -> Main World, lifesteal_world -> Lifesteal; vanished label.
- Read LuckPerms, Vault and Essentials directly (no PlaceholderAPI needed).
- Commands to keep (proposed, unconfirmed): reload, group/player prefix editing, nametag show/hide, `/sbd` toggle, parse.
- Known TAB warnings in the old setup: belowname returned decimals (use whole-number balance), `static-number` unknown key, `lunarServer` interval 120 -> 100.
